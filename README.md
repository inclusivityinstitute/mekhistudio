# Mekhi Studio

Mobile-first student learning studio. This repository contains the standalone student website at `index.html`.

## Deploy with Netlify

1. In Netlify, choose **Add new project → Import an existing project → GitHub**.
2. Select `inclusivityinstitute/mekhistudio` and branch `main`.
3. Leave the build command empty and set publish directory to `.`.
4. Deploy and test the assigned Netlify URL on Mekhi's iPhone.

The application currently saves student progress in the browser unless parent-managed reporting is separately configured and tested. A GitHub repository's privacy settings do not protect a deployed public website. Never put personal financial, medical, immigration or family emergency records in the website source or public forms.

**Note:** This first commit is a standalone interactive version. Additional source files and automatic reporting integration remain separate work.
